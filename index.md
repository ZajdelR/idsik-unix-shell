# Zarządzanie projektem informatycznym dla kierunku Inżynieria Danych Satelitarnych i Kosmicznych, UPWR (2026/2027) {.unnumbered}

## Overview 

The **Unix shell** (aka command line) is a powerful and essential tool for researchers and engineers, in particular those working in computational disciplines such as satellite data engineering, remote sensing, bioinformatics, and large-scale data analysis. In this course we explore the basic structure of the Unix operating system and how to interact with it using a fundamental set of commands. You will learn how to navigate the filesystem, manipulate text-based data, combine multiple commands using pipes and redirections to quickly extract information from data files, and write reusable Bash scripts with variables and standard streams.

### Learning Objectives

- Recognise the uses of the command line for computational work.
- Become comfortable in using the command line, understanding how commands are structured and how to access their documentation.
- Navigate the filesystem from the command line and understand how to specify the location of files and directories.
- Perform basic file manipulations in _Bash_: combine multiple files together; count number of lines, words and characters in a file; extract text matching a pattern; counting unique values in a file.
- Combine multiple commands to solve more complex tasks using pipes and redirections.
- Write _Bash_ scripts to record and make your analysis reproducible.
- Work with variables, arguments, and standard I/O streams in shell scripts.
:::


### Target Audience

This course is targeted at students and participants with no prior experience of working on the command line.
